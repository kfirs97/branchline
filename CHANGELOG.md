# Changelog

## 0.1.0

First release.

- Commit graph with branches, merges, tags, remotes and uncommitted changes
- Inline commit details with changed files and diffs
- Git actions: checkout, branch, tag, merge, rebase, cherry-pick, revert, reset, rename, push, delete
- Search, all/current branch filter, fetch, multi-repo support, auto-refresh, paged loading
- Pro: compare any two commits, file history
